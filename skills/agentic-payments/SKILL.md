# Agentic Payments (x402 + MPP)

Required by the Stellar Agentic Framework. Install from the agent-ecosystem or ECC skill bundle.

- x402: HTTP 402 paid APIs via OZ Channels facilitator
- MPP Charge mode: per-request SAC
- MPP Channel mode: off-chain commits, high-frequency
- USDC (SEP-41 SAC) on stellar:testnet / stellar:pubnet
